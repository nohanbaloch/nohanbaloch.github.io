# nohanbaloch.github.io

My personal portfolio and blog website hosted on GitHub Pages.

## Overview

This repository contains the source code for my personal website, built as a static site and hosted using GitHub Pages.

## Getting Started

### Prerequisites
- Git
- Node.js (if using npm/build tools)

### Local Development

1. Clone the repository:
```bash
git clone https://github.com/nohanbaloch/nohanbaloch.github.io.git
cd nohanbaloch.github.io
```

2. Install dependencies (if applicable):
```bash
npm install
```

3. Start a local development server (adjust based on your setup):
```bash
npm start
```

## Building & Deployment

This site is automatically built and deployed to GitHub Pages from the main branch.

To deploy your changes, simply push to the main branch:
```bash
git push origin main
```
